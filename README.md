## Local Development

1. [Install Flox](https://flox.dev/docs/install-flox/install/)
1. Activate Flox

   ```shell
   flox activate
   ```

   _Optinal_: Set up direnv for [auto activate](https://flox.dev/popular-packages/auto-environment-activation-with-direnv-flox/)

1. Start local server

   ```shell
   just serve
   ```

## Create new post

```sh
just post $TITLE
```
